# 抖音表情保存助手

可直接加载的 Chrome / Microsoft Edge Manifest V3 扩展。无需构建、无需 npm 依赖。面向抖音网页版视频评论区、私信会话和收藏表情面板，保存用户已经打开并显示的图片。

**主要功能：**悬停 / 右键单张保存 · 勾选批量下载 · 懒加载收集 · 保留原格式动画 · 文件命名与重复下载处理。

这是非官方开源项目，与抖音及其运营方无隶属关系。当前版本已通过本地自动化测试及 Edge 合成页面测试，真实抖音登录后的业务界面仍待验证。

## 下载

- 仓库页面选择 **Code → Download ZIP**，解压后找到包含 `manifest.json` 的目录，即可加载。
- 如果提供了 Releases 安装包，也可下载 `douyin-sticker-saver-v1.0.0.zip` 后解压安装。
- 开发者可以克隆本仓库，直接加载仓库根目录，无需编译。

## 安装（约一分钟）

1. 下载并解压 ZIP，保留整个项目文件夹（GitHub 源码包通常名为 `douyin-sticker-saver-main`）。
2. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的项目文件夹，不是 ZIP，也不是上一级目录。
5. 打开或刷新抖音网页版，登录自己的账号。把扩展固定到工具栏以方便打开面板。

这里提供的是未上架的源码扩展，不是双击安装的 CRX。更新文件后，在扩展管理页点击重新加载，再刷新抖音页面。卸载时在扩展管理页选择“移除”；已经下载的图片不会被删除。

## 使用

### 单张

- 将鼠标移到图片上，点击“↓ 保存”。此入口也支持普通图片，避免启发式筛选漏掉表情。
- 或右键图片，选择“保存这张表情 / 图片”。CSS 背景图片可以使用页面右键菜单，但必须右键到该图片所在元素。
- 右键菜单被网页拦截时使用悬停按钮。安装后原先打开的页面必须刷新。

### 评论、私信与收藏表情批量保存

1. 手动打开目标视频评论、私信会话或收藏表情列表。扩展不会替你打开私信、切换会话或拉取后台列表。
2. 点击浏览器工具栏中的扩展图标，打开右侧面板。
3. 慢慢滚动目标区域，使需要的表情实际显示；懒加载完成后会自动收集，滚出视口的已收集项保留。
4. 默认“疑似表情”使用元素描述、类名和尺寸筛选，可能误收或漏收。切换“全部已显示图片”可人工筛选，头像和普通图片也可能出现。
5. 勾选所需图片，或“全选当前列表”，再点击“下载勾选项”。批量仅下载当前筛选中勾选的项目；隐藏筛选项不会加入这次队列。
6. 查看卡片状态与浏览器下载页（Ctrl+J）。界面“已提交”表示开始下载，不等同于下载成功。

每页最多缓存 500 个不同 URL，最多跟踪 6000 个候选元素。达到上限后可先下载，再清空列表并继续滚动。刷新页面或网页 URL 变化会清空当前图片列表；URL 变化也会停止尚未提交的批量队列。关闭面板不会停止收集或排队，“停止排队”才会停止后续提交，已经提交的任务请在浏览器下载页取消。

## 动画、命名与去重

- 直接交给浏览器下载原图片 URL，不截图、不使用 Canvas、不转码、不删除 URL 查询参数，也不猜测“原图”接口。页面当前资源若是动态 GIF、WebP 或 APNG，其动画字节会保留；页面只提供静态预览时，扩展不能恢复原本不存在于该资源中的动画。
- 优先使用服务器返回的 MIME 类型确定扩展名，支持 GIF、WebP、PNG/APNG、JPEG、AVIF、BMP、ICO。无可靠类型时仅使用可信图片后缀；仍无法识别则保存为 `.img`，不会擅自标为 GIF。HTML、SVG 及其他不支持的明确类型会被取消下载。
- 输出位于浏览器默认下载目录下的 `Douyin-Stickers/UTC日期/图片名称_URL哈希前16位.格式`。名称会清除路径分隔符、控制字符和 Windows 保留名称，最长 48 个字符。文件重名时浏览器添加序号，不覆盖旧文件。
- 按**完整资源 URL 的 SHA-256** 去重，覆盖当前页面、不同标签页和重启后的下载记录。已完成且未被浏览器标记删除的文件默认跳过，正在下载的项目始终跳过。中断或启动失败可重试；勾选“允许重复下载”可重新下载已完成项目。
- 同一图片若有不同签名参数、裁剪尺寸或 CDN 地址，会视为不同资源；本版本不做图片内容哈希。浏览器对外部手动删除文件的检测可能有延迟，此时使用“允许重复下载”。
- “清除本地去重记录”仅移除本扩展已结束的去重记录，不删除文件，不删除浏览器下载历史；正在下载的记录保留。

## 兼容边界与故障排查

| 情况 | 说明 / 处理 |
| --- | --- |
| 没有图片 | 打开实际列表并滚动，尝试“全部已显示图片”和重新扫描。 |
| 没有悬停按钮 | 确认当前地址是 HTTPS 的 douyin.com 或子域，并刷新页面。Canvas、视频、封闭 Shadow DOM、伪元素图片不支持。 |
| 背景图漏收 | 支持单层 CSS background-image。批量扫描覆盖内联 background 样式及 emoji/sticker 类名；其他背景图可尝试悬停或右键。不拆分精灵图或多层背景。 |
| 跨域 iframe 内的图片 | 本版本仅扫描顶层页面，不进入 iframe。 |
| HTTP / Data URL 图片 | 本版本不支持，只接受 HTTPS 图片和当前页面同源 Blob URL。 |
| 403 / 登录过期 / 链接失效 | 在抖音正常重新登录或重新打开图片，刷新列表后重试。不会修改 Referer、伪造令牌或绕过服务器限制。 |
| Blob 下载失败 | 图片的 Blob 可能已被页面回收，重新显示图片后立即下载。 |
| 下载成功但不是动态图 | 页面可能使用静态预览；另外部分系统图片查看器不播放动态 WebP，可在浏览器中打开文件检查。 |
| 预览空白但原页面正常 | 预览采用无 Referer 图片请求；部分 CDN 会拒绝。可以回到页面悬停尝试，实际下载仍可能受站点策略限制。 |
| 每张都弹出保存对话框 | 检查浏览器“下载前询问每个文件的保存位置”设置或组织策略。扩展不会修改这些设置。 |
| 图标出现“抖音”或“刷新” | 在抖音 HTTPS 页面使用，并在扩展安装/更新后刷新页面。 |

抖音的页面结构与资源策略可能变化。本版本没有依赖固定的混淆类名，也没有调用抖音内部接口；不承诺所有表情都能识别、所有资源都允许重新下载。真实登录后的三个业务界面尚未完成现场验证，具体测试范围见 [TESTING.md](TESTING.md)。

## 权限和安全

详细说明见 [SECURITY.md](SECURITY.md)。仅申请 `downloads`、`storage`、`contextMenus`，内容脚本仅匹配 HTTPS 抖音域名；没有全站读取权限、Cookie 读取权限、网络拦截权限或远程代码。

## 开发与测试

源码结构：`manifest.json` 声明权限；`content.js` 负责发现图片和页面面板；`background.js` 负责下载、状态与去重；`core.js` 提供安全校验及文件命名。全部使用原生 JavaScript。

安装 Node.js 20 或更高版本后，在项目目录运行：

```sh
node --test tests/core.test.js tests/background.test.js
node --check content.js
node --check background.js
```

浏览器冒烟测试（需要本机 Chromium 浏览器，可通过 `BROWSER_PATH` 指定可执行文件）：

```powershell
$env:BROWSER_PATH = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
node tests/browser-smoke.mjs
```

该测试使用独立临时浏览器配置与合成页面，不使用你的浏览记录或登录信息；保存截图与测试下载到当前目录的 `work` 文件夹。测试用域名请求由本地浏览器调试接口拦截替换，不代表真实抖音页面测试。生产扩展不包含任何浏览器调试权限。

参考：[Chrome Downloads API](https://developer.chrome.com/docs/extensions/reference/api/downloads)、[Content Scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[Context Menus API](https://developer.chrome.com/docs/extensions/reference/api/contextMenus)。
